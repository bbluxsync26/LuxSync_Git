## The Surface

The site is designed to feel like premium interior architecture with technology built into the material itself.

| Layer | Direction |
|---|---|
| Canvas | Slate Navy, with Dark Suede surfaces for elevation |
| Light | Concealed Dusty Steel underlight, softened by warm neutrals |
| Detail | Restrained Champagne Rose Gold Metallic edges and accents |
| Type | Manrope for headings and controls; Inter for reading and forms |
| Motion | Short, quiet press and release states; reduced motion respected |

Glow is never the only state cue. Contrast, focus indicators, readable labels, and truthful interaction affordances stay in charge.

## What It Builds

- Static HTML generated by Node.js
- Responsive CSS using the approved LuxSync palette
- Vanilla JavaScript for the Concierge, Blueprint, adaptive Contact flow, FAQ accordions, and catalog surfaces
- Exact protected LuxSync logo masters copied into the build
- Commerce links that defer to GoDaddy Commerce Plus when configured

The build reads from the repository sources of truth. Imported raster boards and crops remain reference-only unless an asset manifest marks them production-approved.

## Requirements

- Node.js 20 or later
- A checkout with the governed `brand/`, `content/`, and `website/` sources available

## Build And Test

```bash
cd site
npm run build
npm test
```

`npm test` rebuilds the site and runs the static checks in `test.mjs`. Deployable output is written to `site/dist/` and is intentionally not committed.

## Source Layout

| Path | Purpose |

## Runtime Integration

Set these build environment variables when the corresponding integration is available:

- `LUXSYNC_COMMERCE_URL` - live Commerce Plus storefront URL. When unset, Shop CTAs route to product-information contact instead of inventing a store destination.
- `LUXSYNC_CONTACT_ENDPOINT` - HTTPS JSON form endpoint. When unset, the adaptive Contact form prepares an email to the correct LuxSync inbox instead of claiming the web form was received.
- `LUXSYNC_SITE_URL` - canonical production site URL for future absolute-link and SEO expansion.

## Customer State

The Concierge stores in-progress answers and the generated Blueprint in browser `localStorage`. This lets a customer move from the Concierge to My LuxSync Blueprint and then into Contact without re-entering active-session context.

No medical information should be collected through these flows.
