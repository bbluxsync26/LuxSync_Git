# LuxSync Production Site

This directory is the deployable LuxSync website implementation built from the repository's governed website, content, Concierge, catalog, and brand source of truth.

## Stack

- Static HTML generated by Node.js
- Shared responsive CSS using the approved LuxSync palette
- Vanilla JavaScript for the Concierge, Blueprint, adaptive Contact flow, FAQ accordions, and catalog surfaces
- Exact protected LuxSync logo masters copied into the build
- GoDaddy Commerce Plus remains the live commerce system of record

## Build

```bash
cd site
npm run build
npm test
```

The deployable output is written to `site/dist/` and is intentionally not committed.

## Runtime integration variables

Set these as build environment variables when available:

- `LUXSYNC_COMMERCE_URL` — live Commerce Plus storefront URL. When unset, Shop CTAs route to LuxSync product-information contact instead of inventing a store destination.
- `LUXSYNC_CONTACT_ENDPOINT` — HTTPS JSON form endpoint. When unset, the adaptive Contact form prepares an email to the correct LuxSync inbox instead of falsely claiming the web form was received.
- `LUXSYNC_SITE_URL` — canonical production site URL for future absolute-link/SEO expansion.

## Customer-state behavior

The Concierge stores in-progress answers and the generated Blueprint in browser `localStorage` so a customer can move from the Concierge to My LuxSync Blueprint and then into Contact without re-entering active-session context. No medical information should be collected through these flows.

## Brand guardrails

The build uses only the approved palette and exact protected logo assets. Imported raster boards/crops outside `brand/assets/01-logos/` remain reference-only and are not wired into the live site.
