## Provenance and Usage

- The approved reference heroes remain archived under `brand/reference-boards/hero-style-examples/`.
- `luxsync-home-approved-showcase.png` and `luxsync-roi-guide.png` are site delivery copies of approved reference artwork.
- The remaining coordinated route heroes were generated with Adobe Firefly using the approved smart-living showcase as visual guidance.
- Website headings, body copy, calls to action, contact details, and accessibility text remain live HTML.
- The page-hero overlay intentionally masks the copy-safe left field of generated imagery so only governed HTML communicates page content.
- Do not extract or rely on incidental generated interface text as factual product or commerce content.
