# LuxSync Brand Assets v3

**LuxSync LLC**  
*Where Luxury Lives Intelligently*

This directory is the authoritative visual asset system for LuxSync going forward.

## Non-negotiable logo rule

The approved logo masters are immutable artwork. Do not redraw, retype, recolor, soften, cartoonize, or regenerate them. New compositions must reference the approved logo files directly.

Canonical protected masters:

- `../assets/01-brand/luxsync-monogram-orb.png`
- `../assets/01-brand/luxsync-horizontal-lockup.png`

## Approved palette

- Slate Navy `#0D1526`
- Dark Suede `#172036`
- Pale Driftwood `#D0BEB0`
- Warm Taupe Mauve `#9E8B85`
- Antique Rose Taupe `#967878`
- Dusty Steel `#7B96B2`
- Champagne Rose Gold Metallic, with `#D6B0A0` as the approved metallic anchor

No other brand/UI colors are permitted. Natural photography may contain natural scene color, but branded overlays, controls, icons, typography, borders, and accents must stay inside this palette.

## Typography

- **Manrope 500/600**: headings, navigation, CTA labels, buttons, badges, graphic UI
- **Inter 400/500**: body copy, forms, captions, product descriptions, supporting UI
- **Logo lettering**: approved artwork only, never recreated with a font

## Structure

- `00-reference/` canonical brand-board and usage reference
- `01-foundation/` palette and system foundations
- `02-ui/` buttons, CTAs, badges, controls
- `03-icons/` line iconography
- `04-heroes/` new website hero compositions
- `05-ecommerce/` product and trust components
- `06-stationery/` business cards, letterhead, invoice
- `07-marketing/` social, email, flyer, promo layouts
- `08-docs/` manifests and migration notes

## Migration rule

`brand/assets/` is legacy compatibility content. New work must use `brand/assets-v3/`. Existing website/document references should be migrated to v3 as they are touched. The legacy generator must not be used to recreate v3 logos or graphics.
