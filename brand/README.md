## Quick Reference

### Design Principles

**Intelligent Calm** — Professional yet approachable  
**Luxury Through Simplicity** — Premium without complexity  
**Curation Over Complexity** — Intentional selection  
**Trust Before Transactions** — Relationships matter  
**Excellence in Every Detail** — Quality at all touchpoints

### Typography Goals

Embody these qualities:
- Warm — Genuine and approachable
- Comfortable — Easy to read, never harsh
- Refined — Premium quality throughout
- Human — Conversational, not robotic
- Modern — Clean, current aesthetic
- Effortless — Simple, intuitive experience

### Color Usage

| Purpose | Color | Hex |
|---------|-------|-----|
| Backgrounds | Slate Navy | `#0D1526` |
| Card Surfaces | Dark Suede | `#172036` |
| Text (Primary) | Pale Driftwood | `#D0BEB0` |
| Text (Secondary) | Warm Taupe Mauve | `#9E8B85` |
| Accents & Decorative | Antique Rose Taupe | `#967878` |
| CTAs & Interactive | Dusty Steel | `#7B96B2` |

### Font Stacks

```css
/* Headlines */
font-family: "Manrope", system-ui, -apple-system, sans-serif;

/* Body & UI */
font-family: "Inter", system-ui, -apple-system, sans-serif;
```

## Using Brand Guidelines

### In Design Tools
1. Import brand colors as color swatches
2. Apply Manrope for all headings
3. Apply Inter for all body text and UI
4. Reference asset library for icons and graphics

### In Code & Markup
1. Use color hex codes from [colors.md](colors.md)
2. Import fonts from Google Fonts
3. Apply typography hierarchy from [typography.md](typography.md)
4. Reference SVG assets from `assets/` folder

### In Writing & Content
1. Follow brand voice from [voice-and-tone.md](voice-and-tone.md)
2. Embody "Intelligent Calm" personality
3. Write warm, professional, thoughtful copy
4. Avoid pushy, corporate, or technical tone
