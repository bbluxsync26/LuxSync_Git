# LuxSync Brand Guidelines

**Luxury Orbit — Active Web Visual System**

> Where Luxury Lives Intelligently

## Direction

Luxury Orbit is the current website and web-graphics direction. It combines deep architectural navy, warm rose-gold metal, soft powder-blue orbit light, pale blush surfaces, refined serif branding, and quiet premium UI components.

The desired impression is **luxury interior design with intelligent technology quietly underneath it**.

## Core Visual Language

- Deep Navy `#0B1D3A`
- Midnight Blue `#172846`
- Pale Blush `#F3ECE8`
- Taupe `#A69A8E`
- Dusty Rose `#E7B5B8`
- Soft Powder Blue `#A6B9CE`
- Rose-gold metallic gradients anchored around `#D6B0A0`
- Blue orbit/glow used as a restrained technology signature
- Rounded dark cards with warm metallic edges
- Spacious layouts with selective atmospheric glow

## Typography

- Wordmark/editorial accent: Bodoni Moda / Bodoni MT / Didot / Georgia
- Headings and graphic UI: Century Gothic with Montserrat fallback
- Body and supporting UI: Candara with Inter / Segoe UI fallback

See [typography.md](typography.md) for implementation details.

## Asset Library

The library contains **97 logical SVG masters**, with matching PNG and WebP exports plus catalog contact sheets.

Assets live under [assets/](assets/):

- `01-brand/` logos and brand marks
- `02-icons-brand/` decorative and brand-principle icons
- `03-icons-website/` functional web icons
- `04-icons-social/` social icons
- `05-palette/` palette and texture tiles
- `06-gradients/` atmospheric backgrounds
- `07-components/` buttons, badges, controls, trust components
- `08-cards/` brand and content cards
- `09-illustrations/` smart-home and visual-system illustrations
- `10-product-cards/` commerce category cards
- `11-banners/` hero, shop, and guide banners

## Generator

The SVG masters are generated directly in the repository by:

```text
scripts/generate-luxury-orbit-assets.py
```

PNG/WebP siblings and catalog contact sheets are regenerated by:

```text
scripts/regenerate-brand-raster-assets.py
```

**The SVG files do not need to be sent through an image generator.** They are authored as SVG source. Use image generation only when a photographic/interior scene is intentionally required.

## Brand Voice

Keep the existing **Intelligent Calm** voice: warm, confident, thoughtful, unhurried, professional, and human.
