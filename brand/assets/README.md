# LuxSync Web Asset Library

**Luxury Orbit — Web Graphics Collection**

> Where Luxury Lives Intelligently

## Library

This folder contains **97 logical graphics** across 11 numbered categories. Every logical graphic has an SVG master and generated PNG/WebP siblings. The catalog folder also contains preview/contact sheets.

## Source of Truth

- SVG masters are generated by `scripts/generate-luxury-orbit-assets.py`.
- PNG/WebP files are generated by `scripts/regenerate-brand-raster-assets.py`.
- `00-catalog/SVG-ASSET-LIST.md` is the generated list of all SVG masters.
- SVG should be preferred for logos, icons, controls, badges, gradients, and other vector UI.
- WebP should be preferred for larger web-delivery graphics when a raster format is more practical.
- PNG remains the compatibility/transparency fallback.

## Transparency

Transparent backgrounds are used for logos, icons, social marks, and standalone controls where practical. Cards, textures, gradients, and banners intentionally include their designed surfaces.

## Regeneration

Run:

```bash
python scripts/regenerate-brand-raster-assets.py
```

The script first regenerates all 97 SVGs, then renders their PNG/WebP siblings and rebuilds catalog contact sheets.

## Image-generation boundary

No SVG in this library requires an image generator. The repository generator creates the SVG source directly. For future photographic scenes, generate the raster scene separately and keep website text, controls, and branding as HTML/CSS or SVG overlays so copy remains editable and accurate.
