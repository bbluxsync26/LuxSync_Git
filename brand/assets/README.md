# LuxSync Clean Atomic Production Assets

**Version:** 6.0 clean atomic triple-format
**Official slogan:** Where Luxury Lives Intelligently

This directory is the only deployable LuxSync graphic asset library.

- `logos/` contains exact protected artwork in SVG fidelity-container, PNG master and WebP delivery formats.
- `icons/` contains clean semantic vector icons rebuilt as atomic artwork.
- `dividers/` contains clean vector dividers, orbit strokes and ornamental accents.
- `qa/` contains rendered contact sheets for visual review only.

Every production asset has matching SVG, PNG and WebP files with the same semantic basename. Buttons, forms, cards, navigation and other interactive UI remain live HTML/CSS rather than raster screenshots. The old numbered grid-sliced asset folders are retired. Protected logo lettering is never retyped or regenerated.
