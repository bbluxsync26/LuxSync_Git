# LuxSync Clean Atomic Digital Delivery Assets

**Version:** 6.0 clean atomic triple-format  
**Status:** Active / Validated digital delivery layer  
**Official slogan:** Where Luxury Lives Intelligently

This directory contains the current clean, deployable **digital delivery layer** of the LuxSync brand system. It is not the full definition or full future inventory of LuxSync branding.

The broader omnichannel system is governed by `brand/README.md`, the permanent approval evidence under `brand/reference-boards/`, and PR-BRAND-001.

Current completed families:

- `logos/` contains exact protected artwork in PNG, WebP and SVG fidelity-container delivery formats.
- `icons/` contains clean semantic vector icons rebuilt as atomic artwork.
- `dividers/` contains clean vector dividers, orbit strokes and ornamental accents.
- `qa/` contains rendered contact sheets for visual review only.

Every current production asset in this directory has matching SVG, PNG and WebP files with the same semantic basename and is governed by `asset-manifest.json`.

Buttons, forms, cards, navigation and other interactive UI remain live HTML/CSS for website/app implementation rather than flattened screenshots. This does **not** revoke the approved visual concepts shown on the reference boards or remove those concepts from the omnichannel brand system.

The old numbered grid-sliced production folders are retired because they contained malformed or contaminated board crops. Protected logo lettering is never retyped or regenerated.

For print, merchandise, stationery, video-ready static art and other physical/digital channels, use the omnichannel master/export system governed by:

- `brand/manifests/omnichannel-brand-manifest.json`
- `brand/audit/brand-build-state.json`
- `prompts/branding/PR-BRAND-001-LuxSync-Omnichannel-Brand-System-Recovery-Audit.md`
