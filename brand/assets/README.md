# LuxSync Web Asset Library

**Luxury Orbit — Web Graphics Collection**

> Where Luxury Lives Intelligently

## Library

This folder contains **104 logical assets** across 12 numbered categories:

- **98 SVG-based graphics** with generated PNG/WebP siblings
- **6 production raster scenes** with optimized PNG/WebP versions

The catalog folder also contains preview/contact sheets for the SVG-based library.

## Source of Truth

- SVG masters are generated by `scripts/generate-luxury-orbit-assets.py`.
- SVG-derived PNG/WebP files and contact sheets are generated by `scripts/render-luxury-orbit-assets.py`.
- `00-catalog/SVG-ASSET-LIST.md` lists all 98 SVG masters.
- `asset-manifest.csv` is the canonical detailed inventory.
- SVG is preferred for logos, icons, controls, badges, gradients, and other vector UI.
- WebP is preferred for production scene photography and larger raster graphics.
- PNG remains the compatibility/transparency fallback.

## Active Theme

Luxury Orbit uses the authoritative **Plush Drift v2.1** base palette.

| Role | Color | Hex |
|---|---|---|
| Primary background | Slate Navy | `#0D1526` |
| Elevated surface | Dark Suede | `#172036` |
| Primary light text/surface | Pale Driftwood | `#D0BEB0` |
| Secondary neutral | Warm Taupe Mauve | `#9E8B85` |
| Warm decorative accent | Antique Rose Taupe | `#967878` |
| Cool interactive/orbit accent | Dusty Steel | `#7B96B2` |
| Premium metallic accent | Champagne Rose Gold Metallic | `#D6B0A0` anchor |

Champagne Rose Gold Metallic uses an approved light-to-dark metallic gradient around its `#D6B0A0` anchor. Dusty Steel is the anchor for the restrained orbit/glow signature.

## Typography

- **Manrope 500/600** — display, headings, logo/wordmark construction
- **Inter 400/500** — body copy, UI, controls, labels, supporting text

Legacy Century Gothic, Candara, Bodoni, Didot, and similar declarations are not part of the current standard.

## Category 12: Production Scenes

`12-scenes/` contains text-free raster photography intended to sit underneath native website copy and vector branding:

- `home-hero-room`
- `shop-smart-home-hardware`
- `roi-guide-backdrop`
- `smart-hub-vignette`
- `dashboard-tablet-scene`
- `mobile-automation-scene`

These files intentionally contain **no baked-in LuxSync logo, headline, navigation, buttons, prices, ratings, or promotional claims**.

## Transparency

Transparent backgrounds are used for logos, icons, social marks, and standalone controls where practical. Cards, textures, gradients, banners, and photographic scenes intentionally include their designed surfaces.

## Regeneration

Run:

```bash
python scripts/regenerate-brand-raster-assets.py
```

This regenerates the 98 SVG-based asset sets and catalog sheets. Production scenes in `12-scenes/` are curated raster source assets and are not recreated by the SVG generator.

## Image-generation Boundary

No SVG in this library requires an image generator. Use image generation only for deliberately photographic/interior/product scenes. Keep website text, controls, navigation, commerce data, and branding native in HTML/CSS or SVG so copy remains editable, accessible, and typographically accurate.
